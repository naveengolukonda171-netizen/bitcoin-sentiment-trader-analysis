# Bitcoin Sentiment Trader Analysis

## Overview
This project analyzes the relationship between Bitcoin Fear & Greed sentiment and Hyperliquid trader performance.

### Datasets
1. Bitcoin Fear & Greed Index
2. Hyperliquid Historical Trader Data

### Objectives
- Analyze trader profitability across sentiment regimes
- Compare win rates during Fear vs Greed
- Study trading activity and risk-taking behavior
- Generate actionable trading insights

### Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
